每页整段生成自然语音，并保存TTS实际单词边界。字幕语句与配音逐字对应，通过词边界对齐；不是把整篇讲稿按字符数平均分配时间。

为精确达到4分钟，仅去除每页末尾生成的多余静音，所有语音文字完整保留。前16页作统一约1.017倍、保持音高的微调，结束页配音原速。翻页落在语音结束后，不截断句子。音频已进行两遍响度归一化，约-18 LUFS、最高真峰值-1.5 dBTP。
