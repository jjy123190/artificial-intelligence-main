## 复核方法（默认不写文件）

在项目根目录打开PowerShell：

```powershell
Set-Location 'deliverables/lab3_备份/可选拓展_20261113'
python -B -X utf8 verify_examples.py
python -B -X utf8 verify_report.py
Set-Location ../../..
```

- `verify_examples.py`：仅依赖Python标准库，重放给定证明/计划并检查8个负例；不调用搜索器或模型。若明确需要另存记录，可加 `--output <JSON路径>`。
- `verify_report.py`：依赖当前环境已安装的 `python-docx`、`lxml`、`PyMuPDF`，只读核对发布清单、样例重放、Word/PDF文字、表号/分页、原文原表和493个既有文件指纹；还对21个未改版面做像素级比较。可选 `--write-record` 只写本目录 `qa/release_validation.json`，不会更新发布清单。
- `--staged` 只检查本目录暂存稿，不代表已发布验收。
- 若以后自行改动报告或项目，清单不通过是版本变化提示。不要通过自动重写清单来掩盖差异。

## 本目录文件

| 文件/目录 | 用途 |
| --- | --- |
| `before/` | 修改前用户保存版DOCX及原PDF快照；与更早的备份根目录报告分开保留 |
| `draft/` | 从当前用户版增补后的暂存DOCX/PDF |
| `第14章_可选迁移拓展.md`、`extension_content.json` | 本次新增章节的可编辑内容，不是原报告全文的替代稿 |
| `verify_examples.py`、`example_verification.json` | 样例核验程序、完整中间状态和错误拒绝记录 |
| `reference_checks.json` | Lean官方等式文档和STRIPS论文Crossref元数据核验记录 |
| `build_extension.py` | 仅从 `before/` 副本增补正文；不写正式目录，不全量重建原报告 |
| `export_staged.py` | 用独立隐藏Word实例导出暂存PDF与预览；不会关闭用户的Word实例 |
| `verify_report.py` | 最新版只读报告核验入口 |
| `publish_report.py` | 单次安全发布工具：输入指纹必须与修改前一致，且目标Word无未保存改动；不要日常重复运行 |
| `release_manifest.json` | 本次30页正式报告与支持材料的SHA-256清单 |
| `qa/` | 修改基线、明确修改范围、预览、视觉检查及本次验收记录 |
