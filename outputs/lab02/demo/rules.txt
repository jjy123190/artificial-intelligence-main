规则库共 27 条

R01: Holds(?x,?y,?r) → DirectControls(?x,?y) [含守卫]
  单方直接持股超过 50% → 绝对控股线索
  边界：不输出自身控制；不覆盖表决权委托、董事会席位及协议控制。
R02: Kin(?p,?q,?rel) → Concerts(?p,?q) [含守卫]
  配偶视为一致行动人（教学假设）
  边界：配偶并不在现实中无条件等于一致行动人。
R03: KinEvidenced(?p,?q) → Concerts(?p,?q)
  亲属关系具有公开佐证 → 一致行动候选
  边界：无佐证的亲属关系不触发本规则。
R04: Concerts(?p,?q) ∧ Holds(?p,?c,?r1) ∧ Holds(?q,?c,?r2) → DirectControls(?p,?c) [含守卫]
  一致行动人合计超过 50% → 持股较多者控制候选
  边界：只合计两人；份额相等时保留两个候选，不声称控制人唯一。
R05: DirectControls(?x,?a) ∧ Holds(?a,?c,?r1) ∧ Holds(?x,?c,?r2) → DirectControls(?x,?c) [含守卫]
  自身与所控企业的直接持股合计超过 50% → 控制候选
  边界：复现 C1 与 C2 合计持有 C3 的 55%；不是多子公司任意集合加总。
R05b: DirectControls(?x,?a) ∧ Holds(?a,?c,?r1) → DirectControls(?x,?c) [含守卫]
  所控企业单独持股超过 50% → 控制向上穿透
  边界：不是缺省否定规则；不假定没有记录就没有直接持股。DirectControls 含穿透控制候选。
R06: Holds(?x,?y,?r) → NotControlsByHalf(?x,?y) [含守卫]
  单条恰好 50% 的持股记录不足以支持绝对控股
  边界：该谓词不是 Controls 的逻辑否定；一致行动等其他证据仍可能支持控制。
R07: Controls(?x,?y) ∧ Controls(?y,?z) → Controls(?x,?z) [含守卫]
  控制传递（不输出自身控制自身）
R08: DirectControls(?x,?y) → Controls(?x,?y)
  将 DirectControls 纳入 Controls
R09: Controls(?p,?c) ∧ Person(?p) ∧ Company(?c) → ActualController(?c,?p)
  控制企业的自然人 → 实际控制人候选
R10: Holds(?a,?b,?r) → HoldReach(?a,?b)
  持股可达：基础边
R11: HoldReach(?a,?b) ∧ Holds(?b,?c,?r) → HoldReach(?a,?c)
  持股可达：传递闭包（保留回到自身的路径）
  边界：不能排除 ?a=?c，否则循环持股预警永远无法触发。
R12: Guarantee(?a,?b,?m) → GuarReach(?a,?b)
  担保可达：基础边
R13: GuarReach(?a,?b) ∧ Guarantee(?b,?c,?m) → GuarReach(?a,?c)
  担保可达：传递闭包（保留回路）
R14: ActualController(?a,?p) ∧ ActualController(?b,?p) → SharedController(?a,?b) [含守卫]
  同一自然人控制的不同企业 → 共同控制关系
R15: SharedController(?a,?b) ∧ Trade(?a,?b,?m) → RelatedTrade(?a,?b)
  共同控制企业之间的实际交易 → 关联交易线索
R16: SharedController(?a,?b) ∧ Trade(?b,?a,?m) → RelatedTrade(?b,?a)
  共同控制关系反向匹配交易（等价冗余规则，用于去冗余实验）
R17: ElevatedReach(?a,?b) → OpaqueLayer(?a,?b)
  存在三层及以上简单持股路径 → 多层结构线索
  边界：输入由路径预处理得到（上限8层）；多层不等于违法。
R18: Holds(?x,?s,?r) ∧ Shell(?s) → OpaqueShell(?x,?s)
  持有低资本且未见交易记录的企业 → 壳结构候选
  边界：注册资本≤500万元且样本无交易只是代理，不能认定真实空壳。
R19: RelatedTrade(?a,?b) ∧ Listed(?b) → Alert(?b,关联交易待核查)
  上市买方存在关联交易线索 → 待核查预警
R19b: RelatedTrade(?a,?b) ∧ Listed(?a) → Alert(?a,关联交易待核查)
  上市卖方存在关联交易线索 → 待核查预警
R20: HoldReach(?a,?a) → Alert(?a,循环持股)
  持股路径回到自身 → 循环持股线索
R21: GuarReach(?a,?a) → Alert(?a,担保圈)
  担保路径回到自身 → 担保圈线索
R22: Alert(?c,?t) → RiskLevel(?c,高)
  有预警 → 高复核优先级
R23: OpaqueLayer(?x,?c) ∧ Company(?c) → RiskLevel(?c,中)
  多层持股路径的目标企业 → 中复核优先级
  边界：不含否定前提；若高、中同时出现，展示层取高。
R23b: OpaqueShell(?x,?c) ∧ Company(?c) → RiskLevel(?c,中)
  壳结构候选企业 → 中复核优先级
R24: HoldReach(?p,?c) ∧ Person(?p) ∧ Company(?c) → BeneficialOwner(?c,?p)
  可达企业的自然人股东 → 受益人候选（非最终认定）
  边界：未计算穿透份额和实际收益；不能称为已确认的最终受益人。
