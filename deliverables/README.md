## 实验四

本目录的整合报告、PPT 和视频对应网页版 `continued`（56.47% / 68.81%）。后续笔记本 GPU 自训的三组对照、权重和演示命令见实验四说明。最终局部匹配方案的 1-shot / 5-shot 为 **74.37% / 82.64%**。[实验四自训结果](../源码/experiments/lab04/README.md#课程自训结果)

### 原版 v1（保留的历史记录）

- `lab4/第33组_实验四_实验报告.docx`
- `lab4/第33组_实验四_实验报告.pdf`
- `lab4/小样本学习与特征校准.pptx`
- `lab4/实验四_Demo.mp4`
- `lab4/实验四_PPT汇报.mp4`

模型Demo为90秒的真实网页操作，PPT讲解为3分钟，包含普通话合成配音和烧录中文字幕。原版模型、表格和讲稿使用同一份真实 mini-ImageNet 评测结果，保留完整方案在5-shot中低于基线的负结果。制作脚本位于 `制作资料/实验四`；临时录音、录制原片和渲染检查图不属于正式交付文件。

视频统一为1920×1080、30fps、H.264/AAC。PPT静态页先转换成连续视频，再逐帧烧录字幕，修复直接处理静态页时字幕缺失的问题；成片核对10页画面和字幕，并检查两段视频的时长与完整解码。CPU部署的结果仅对应本次窄通道模型和固定测试池。
