- 从用户指定的实验三「多跳搜索工作台」开始：三跳 `shared-3`、`GA + 学习 + 专家`、预算 16，尚未运行。

## 验证与文件

- `record_demo.py`：真实浏览器录制脚本。
- `finish_demo.py`：按原始帧时间戳编码、全片解码验证、发布脚本。
- `take_04/audit.json`：真实操作、6次搜索请求/响应、3次下载和错误审计。

- `take_04/contact-sheet.jpg`、`take_04/verification-frames/`：成片抽帧。
- `take_04/frames/`、`capture-frames.json`、`frames.ffconcat`：录制源帧和真实时间戳。
- `coverage.json`：功能覆盖范围与实际操作时间线。
- `protected_before.json`：332个既有源码、运行数据与正式报告/PPT文件的录制前指纹；成片验证时全部未改变。
- `delivery.json`：正式输出位置与 SHA-256。

## 再次制作

在项目根目录运行，使用一个尚不存在的新 take 名称：

```powershell
rtk proxy python -B -X utf8 outputs/lab03_materials/Demo_20261114/record_demo.py --take take_05
rtk proxy python -B -X utf8 outputs/lab03_materials/Demo_20261114/finish_demo.py render-verify --take take_05
```

录制需要当前项目的8766服务正常运行。发布前必须审看抽帧并确认 `visual_review`；发布脚本不会覆盖内容不同的既有正式视频。
