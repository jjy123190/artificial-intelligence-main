# 人工智能课程项目

第33组 · 软件工程5班  
组长：梁镇贤；组员：陈宗波、温文辉、陈宇冲、刘亦达。

我们围绕企业股权与关联关系构建统一实验网站，完成知识表示与知识增强、确定性与不确定性推理，以及多跳路径搜索与智能优化三个实验。网站首页提供三个实验入口，各实验共享案例和基础组件，并保留各自的方法、结果与可视化。

## 文件目录

```text
artificial-intelligence-main/
├─ 源码/                   # 实验一至实验三的完整可运行源码
│  ├─ backend/             # 本地API与任务服务
│  ├─ core/                # 公共知识表示、规则与证据能力
│  ├─ experiments/         # lab01、lab02、lab03
│  ├─ web/                 # 前端源码及已构建网页
│  ├─ data/                # 输入数据与实验配置
│  ├─ outputs/             # 实验结果与证据回放数据
│  ├─ 资料/                # 报告图表、案例及可选拓展核验
│  └─ README.md            # 环境、启动与复现说明
├─ deliverables/
│  ├─ lab1/                # 实验一报告、PPT、Demo与演讲视频
│  ├─ lab2/                # 实验二报告、创新点说明、PPT与视频
│  └─ lab3/                # 实验三报告Word/PDF、PPT与视频
├─ 制作资料/               # 图表制作源与演示视频制作素材
├─ 打开网站.cmd            # 打开统一实验首页
└─ 停止网站.cmd            # 停止本项目网页服务
```

## 网站运行

电脑安装Python 3.11或以上版本后，双击根目录或 `源码` 中的 `打开网站.cmd`。启动器检查网页依赖，并打开包含三个实验入口的首页。网页构建文件和必要实验数据均包含在 `源码` 中，浏览现有功能不需要重新构建前端或下载大模型权重。

`源码` 可独立复制到其他目录运行，不依赖同级报告、PPT或视频。详细依赖、命令行用法和实验复现方法见 `源码/README.md`。

## 实验内容

| 实验 | 主要内容 | 实现位置 |
| --- | --- | --- |
| 实验一 | 知识图谱、产生式规则、框架表示、知识增强与关系查询 | `源码/experiments/lab01/` |
| 实验二 | 一阶逻辑、正向与反向推理、归结、Bayes、模糊推理及混合复核 | `源码/experiments/lab02/` |
| 实验三 | BFS、A*、MCTS、GA启发优化、路径价值学习与LLM辅助搜索 | `源码/experiments/lab03/` |

## 成果材料

我们的实验报告、PPT、Demo和PPT演讲视频按实验存放于 `deliverables`。实验三演讲视频为4分钟，完整展示17页PPT，包含普通话配音和画面内中文字幕。各文件名称见 `deliverables/README.md`。

实验数据包含教学合成图与虚构示例，不作为实际企业风险或合规结论。LLM网页演示明确区分已保存评分回放与真实模型推断；结论由路径、关系与证据核验共同约束。
