# 人工智能课程项目

第33组 · 软件工程5班  
组长：梁镇贤；组员：陈宗波、温文辉、陈宇冲、刘亦达。

实验一至三围绕企业股权与关联关系，完成知识表示与知识增强、确定性与不确定性推理、多跳路径搜索与智能优化。实验四按课程指定题目新增 mini-ImageNet 小样本图像分类与特征校准。四个实验共用网站入口和基础组件，各自保留方法、结果与可视化；图像分类指标不代表股权业务效果。

## 网站运行

电脑安装Python 3.11或以上版本后，双击根目录或 `源码` 中的 `打开网站.cmd`。启动器检查网页依赖，并打开四个实验入口。网页构建文件和必要实验数据均包含在 `源码` 中，正常浏览无需重新构建前端。实验四的轻量权重和演示样本随源码保存，现场推理额外需要 PyTorch 与 Pillow，安装方法见实验四说明。

`源码` 可独立复制到其他目录运行，不依赖同级报告、PPT或视频。详细依赖、命令行用法和实验复现方法见 `源码/README.md`。

## 实验内容

| 实验 | 主要内容 | 实现位置 |
| --- | --- | --- |
| 实验一 | 知识图谱、产生式规则、框架表示、知识增强与关系查询 | `源码/experiments/lab01/` |
| 实验二 | 一阶逻辑、正向与反向推理、归结、Bayes、模糊推理及混合复核 | `源码/experiments/lab02/` |
| 实验三 | BFS、A*、MCTS、GA启发优化、路径价值学习与LLM辅助搜索 | `源码/experiments/lab03/` |
| 实验四 | 轻量ResNet12、二阶MAML、均值方差校准、原型更新与配对消融 | `源码/experiments/lab04/` |

实验四使用标准 mini-ImageNet 类别划分和全部38,400张训练图像。完整校准方案的1-shot结果与基线接近、5-shot低于基线；仅原型更新的1-shot表现更好。原始负结果、95%区间、逐任务记录与模型指纹均保留，方法和适用边界见 [实验四说明](源码/experiments/lab04/README.md)。

## 成果材料

实验报告、PPT、Demo和PPT演讲视频按实验存放于 `deliverables`。实验三演讲视频为4分钟；实验四模型Demo为90秒，PPT讲解为3分钟，均含普通话合成配音和画面内中文字幕。各文件名称见 `deliverables/README.md`。

实验数据包含教学合成图与虚构示例，不作为实际企业风险或合规结论。LLM网页演示明确区分已保存评分回放与真实模型推断；结论由路径、关系与证据核验共同约束。
