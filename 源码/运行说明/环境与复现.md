# 运行环境与实验复现

## 网页环境

我们提供了前端构建文件、三个实验的输入和展示数据。网页使用FastAPI、Uvicorn、Pydantic、HTTPX、NetworkX和NumPy；依赖约束见 `requirements-web.txt`，固定版本见 `运行说明/网页依赖锁定.txt`。双击启动器默认进入统一首页。

## 完整测试环境

在 `源码` 目录执行：

```powershell
python -m pip install -r requirements.txt -r requirements-lab03.txt
python -B -X utf8 -m unittest discover -s tests -t . -v
python -B -X utf8 -m experiments.lab03.verification
```

实验三证据复核会重算保存的评估量和表示分类结果，因此需要PyTorch等依赖，但不需要模型权重。算法测试使用临时目录；文件清单核验与已有结果读取不训练模型。

## 重新计算实验

下面命令会写入实验结果目录，适合在独立副本中执行，以保留报告对应的结果集合。

```powershell
python -B -X utf8 scripts/prepare_lab02.py --force
python -B -X utf8 scripts/prepare_lab03.py --force
```

实验一命令行入口为 `python -B -X utf8 main.py lab01`，效率对照入口为 `python -B -X utf8 main.py lab01 benchmark`。

重新运行实验二后，可执行 `python -B -X utf8 main.py lab02 verify --full-replay` 核对新结果与其源码指纹。运行时间受硬件、系统负载及依赖版本影响，复核时同时检查算法语义、数据划分和结果有效性。

## 真实本地模型推断

```powershell
python -m pip install -r requirements-lab03.txt
python -B -X utf8 scripts/prepare_lab03_model.py
python -B -X utf8 scripts/prepare_lab03.py --force --llm
```

该流程会下载固定模型，并消耗内存、磁盘与计算时间。网页默认使用已保存评分回放；真实推断生成的新结果应与使用的模型、源码和数据成套保存。

## 前端开发

正常浏览使用 `web/dist`。修改前端后，在安装Node.js的环境执行：

```powershell
cd web
npm ci
npm run build
cd ..
```

## 图表与拓展样例

实验三图表及案例记录位于 `资料/实验三`。等式证明与三积木规划核验入口为 `python -B -X utf8 资料/可选拓展/verify_examples.py`，检查两个正例和八个错误分支，结果仅适用于声明的有限规则与样例。

`experiments/lab03/report.py` 和 `scripts/materials` 为辅助生成工具；网站不依赖其运行。正式报告与PPT存放于项目的 `deliverables`，与实验输出分离。
