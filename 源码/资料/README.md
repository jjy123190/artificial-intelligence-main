# 实验支撑资料

我们将实验三报告引用的高清图表、逐步搜索轨迹和原始评估记录保存在 `实验三`。其中 `figures` 为PNG/SVG图表，`evidence/cases` 为搜索案例，`evidence/raw` 为实测数据，图表与案例索引位于 `evidence`。

`可选拓展` 包含等式证明和三积木规划的独立样例核验器及结果。运行 `python -B -X utf8 资料/可选拓展/verify_examples.py` 可检查两个正确样例及八个错误分支。

这些资料为报告提供数据和证据对应关系，不参与网站依赖安装，也不包含PPT或视频制作过程。

证据文件中的实验日期、数据指纹和模型记录用于定位报告对应的结果；源码文件的完整性以根目录 `文件校验清单.json` 为准，运行检查摘要见 `运行说明/验证结果.json`。
